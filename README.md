# ClinicBOT

Telegram-бот для обратной связи и показа актуальной информации о клинике.

## Возможности
- Диалог и сбор обратной связи
- Запрос контактных данных
- Сбор расписания и справочных материалов
- Локальное хранение данных в SQLite

## Основные файлы
- bot.py — Telegram-бот
- AdminPanel.py — административная часть
- llm_agent.py — работа с ИИ
- scraper.py — получение расписания
- cache/ — кэш и локальные данные

## Настройка
Перед запуском настройте зависимости и передавайте Telegram- и Mistral-ключи только через локальную конфигурацию окружения. Не коммитьте ключи, базу обратной связи, контакты и кэш.

Бот может обрабатывать имя, телефон, email и сообщения. Перед реальным использованием настройте согласие, сроки хранения, удаление данных и доступ администратора.

## Статус
Прототип. Проверьте конфигурацию и безопасность хранения данных перед запуском.
